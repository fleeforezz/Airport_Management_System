# Airport Management & Booking System — Workspace Rules

## Design System: Swiss Modernism 2.0
All front-end development in this project follows **Swiss Modernism 2.0**:
- **Zero Radius:** `rounded-none` / `0px border radius` everywhere. No pill buttons or rounded cards.
- **Flat 2D Architecture:** No drop shadows (`box-shadow: none !important;`). Use 1px hairlines (`#E5E7EB` / `#000000`).
- **Color Discipline:** Core Black (`#000000`), Pure White (`#FFFFFF`), Light Gray (`#F5F5F5`), and Accent Swiss Red (`#DC2626`).
- **Typography:** `Inter` (sans) and `JetBrains Mono` (mono). Uppercase labels with tracking 0.08em (`label-caps`), index indicators `[ 01 ]`.
- **Full Design Guides:** Refer to the `design-rules/` folder:
  - `design-rules/DESIGN.md`: Complete design system tokens and specifications.
  - `design-rules/UI_COMPONENTS.md`: Component code patterns (DOs and DON'Ts).
  - `design-rules/AIRPORT_DOMAIN_RULES.md`: Airport codes (IATA/ICAO), PNR, and flight rules.
  - `design-rules/PROMPT_TEMPLATES.md`: Ready-to-use prompt templates for AI code generation.
